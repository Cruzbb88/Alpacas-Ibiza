## 4. UNMAPPED Strings That Leak to Production

**Count: 3 confirmed production leaks**

### LEAK 1 — `press-kit/page.tsx` lines 93–96 (HIGH severity)
```
UNMAPPED — awaiting owner upload to public/press/
```
Rendered inside `AssetCard` sub-component when `asset.enabled === false && asset.url === null`. All four press assets are `enabled: false`. This literal string `UNMAPPED — awaiting owner upload to public/press/` renders on the public press-kit page with NO `NODE_ENV !== 'production'` guard. The `OwnerConfirmBanner` below the cards IS guarded, but this card text is not.

File: `app/[locale]/press-kit/page.tsx:95`

### LEAK 2 — `translations/en.json` contact.gettingHere (HIGH severity)
The translation keys `contact.gettingHere.byCar.body`, `contact.gettingHere.fromAirport.body`, `contact.gettingHere.transit.body`, and `contact.gettingHere.coordinates.body` are present in en.json (lines 517–530), but their VALUES contain `[UNMAPPED — owner confirm]` embedded in the travel direction text.

Since these are the PRIMARY translation values (not fallbacks), they render on the live `/contact` page for all locales. Example:
> "GPS: 38.9861° N, 1.5228° E. Search «Alpacas Ibiza, San Carlos» in Google Maps or Apple Maps. What3Words address: **[UNMAPPED — owner confirm]**."

File: `translations/en.json:517–530`, rendered at `app/[locale]/contact/page.tsx:139–177`

### LEAK 3 — `adopt/page.tsx` UNMAPPED in translation values (MEDIUM severity)
`translations/en.json` adopt section (lines 743–767) contains multiple `__UNMAPPED__` sentinels as actual translation values:
```json
"subtitle": "__UNMAPPED__ — owner to supply hero subtitle",
"benefitsIntro": "__UNMAPPED__ — owner to supply intro sentence",
"benefit1": "__UNMAPPED__ — benefit 1 (e.g. adoption certificate)",
...
```
These will render on the live `/adopt` page since they are the primary values in en.json. The `OwnerConfirmBanner` at the bottom is guarded, but the hero subtitle and all benefit bullets are not.

File: `translations/en.json:743–767`, rendered at `app/[locale]/adopt/page.tsx`

### Not a leak (correctly guarded):
- `sustainability/page.tsx` UNMAPPED card text: guarded by `process.env.NODE_ENV !== 'production'` at line 128
- `yoga/page.tsx`, `workshops/page.tsx`, `press-kit/page.tsx` bottom banners: all routed through `OwnerConfirmBanner` which returns null in production
- `testimonial-card.tsx` `__UNMAPPED__` skeleton: UI-level fail-quiet, not a text leak

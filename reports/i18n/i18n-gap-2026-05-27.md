## Actions Taken

1. **Audit script** — `fix_i18n_temp.js` (ephemeral) flattened EN keys, identified 284 missing per locale.
2. **Sentinel injection** — All 284 missing keys injected into de/it/es/fr with `__UNTRANSLATED__: <EN value>` prefix. Array values get per-element prefix. Gap is now visible in rendered UI.
3. **Dev fallback warning** — `lib/translations.ts` lines 25-27 and 36-38 now emit `console.warn("[i18n] Missing key …")` when `NODE_ENV !== 'production'`. No prod impact.
4. **No auto-translation** — All injected values are EN originals prefixed with `__UNTRANSLATED__:`. Translators must replace them.

## Translator Guidance

Search each locale file for `__UNTRANSLATED__` to find all gaps. Replace the full string value (remove the prefix + EN text, write the target-language translation). Do not delete keys.

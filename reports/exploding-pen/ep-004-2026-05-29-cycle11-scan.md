### Gadget G-011 — Retry on `resend.emails.send`

**Target:** [lib/mailer.ts:78](lib/mailer.ts#L78)
**Why:** Resend has 503 spikes; transient failures drop welcome/quarterly/renewal emails permanently. `lib/retry.ts` already exists, just unused.

```ts
// Before
const result = await resend.emails.send({ ... })

// After (gadget)
import { withRetry } from '@/lib/retry'
const result = await withRetry(() => resend.emails.send({ ... }), {
  retries: 2,
  backoffMs: 500,
  retryOn: (err) => err?.statusCode >= 500 || err?.code === 'rate_limited',
})
```

### Gadget G-012 — Swap raw `fetch` to `fetchWithTimeout` in newsletter SendGrid path

### Gadget G-013 — Dynamic import for `@react-pdf/renderer` (ADR 018 compliance)

**Target:** [app/api/adopt-certificate/route.ts:5](app/api/adopt-certificate/route.ts#L5)
**Why:** Every other optional SDK (Stripe, Mollie) uses dynamic import per ADR 018; PDF route breaks the pattern. Missing package crashes route at import-time, not at request-time.

```ts
// Before
import { renderToStream } from '@react-pdf/renderer'

// After (gadget)
async function importReactPdf() {
  try {
    return await import('@react-pdf/renderer')
  } catch (err) {
    log.warn('[pdf] @react-pdf/renderer missing — returning 503')
    return null
  }
}
// Inside GET:
const pdfLib = await importReactPdf()
if (!pdfLib) return NextResponse.json({ ok: false, code: 'PDF_SDK_MISSING' }, { status: 503 })
const stream = await pdfLib.renderToStream(...)
```

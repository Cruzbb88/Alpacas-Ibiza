## 4 — Extraction Candidates (patterns repeated across 3+ components)

### A — Section Header (title + subtitle centered block)
Appears in: **ChoicePaths, ExperienceCards, FAQ, Features, Timeline, WeavingShowcase** (6 components).
All render an identical structure:
```
<div className="text-center mb-12">
  <h2 className="text-3xl md:text-4xl font-bold text-foreground mb-4">{title}</h2>
  <p className="text-foreground/70 ...">{subtitle}</p>
</div>
```
Each has slight variations (max-w, optional guards). Should be extracted as `<SectionHeader title subtitle className? />`.

### B — Icon-only Button with aria-label gap
Appears in: **ProductCard** (Heart, ShoppingCart), **ReviewCard** (TranslateIcon — has text, borderline), **WeavingShowcase** (ArrowRight), **ChoicePaths** (ArrowRight), **ExperienceCards** (ArrowRight), **Features** (none), **Hero** (ArrowRight). All use Lucide icons without `aria-hidden="true"` or an accessible wrapper. Should be enforced via a `<IconButton>` wrapper that requires `aria-label` or via an eslint rule.

### C — Form field pattern (label + input/textarea, no htmlFor/id linkage)
Appears in: **CommissionForm** and **ContactForm** — identical `<label>` + `<input>` block structure without `htmlFor`/`id` association. Both forms use the same className set and the same `handleChange` pattern. Should be extracted as `<FormField label name value onChange required? type? />` that generates matching `id`/`htmlFor` pairs automatically.

### D — "Book Now" CTA link with conversion tracking
Appears in: **BookingSection** (`<a href={FAREHARBOR_BOOKING_URL} onClick={trackConversion.bookTourClick()}`), **Header** (`<a href={FAREHARBOR_BOOKING_URL}>`), **StickyBookingBar** (`<a href={FAREHARBOR_BOOKING_URL} onClick={...}>`). Three separate `<a>` elements pointing to the same URL. BookTourLink (component #4) exists precisely for this but Header and StickyBookingBar don't use it.

### E — Hardcoded EN default strings in optional props
Appears in: **ChoicePaths** (`title`, `subtitle`), **FAQ** (`title`, `subtitle`), **TenantMap** (`heading`, `largerMapLabel`), **Timeline** (subtitle paragraph), **WeavingShowcase** (`badgeText`). Five components silently serve English to non-EN visitors when the optional prop is omitted. Should use a `useLocaleDefault(key, fallback)` hook or require the caller to pass locale.
